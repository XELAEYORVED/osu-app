# Syllabus Shinkyokushin (Belgique) : du 10e kyu au 3e dan

Source : syllabus officiel fourni par Alex (statut définitif au 01-09-2024). Document interne : ne pas citer l'organisation dans l'interface.

Stamina = jumping squats / sit-ups / push-ups.

## Usage dans l'app
- Progression par grade : chaque grade ouvre ses techniques (fiche en 4 images, checklist).
- L'examen blanc génère ses questions à partir de ce tableau : terminologie, catégorie, grade.
- Suivi de la stamina par grade et compteur japonais (10e kyu : compter jusqu'à 10).
- Nom officiel à utiliser : « Tetsui oroshi ganmen uchi » (7e kyu).
- Question ouverte : le 10e kyu se fait-il en fudo dachi ou en zenkutsu dachi dans le dojo d'Alex ?
